# US v. Google Antitrust Trial — Search Revelations (2023)

> **Type:** Court testimony & exhibits (not the 2024 API leak, but official on-record statements).  
> **Relevance:** Validates systems later named in leak docs.

## Key on-record revelations

### NavBoost & click data

Google VP of Search Pandu Nayak testified that systems using click data (including NavBoost lineage) have existed for **many years** (~2005 era cited in coverage).

### Default search agreements

Chrome default search deal — contextualizes why Chrome-scale data access is technically feasible.

### Ranking complexity

Google argued ranking involves many systems; leak docs list many subsystems (Twiddlers, Ascorer, etc. in analyst writeups).
